# English

Guide for developers who want to contribute to or customize MaruxOS.

## Overview

MaruxOS is built entirely from source using **Linux From Scratch (LFS) 12.0 toolchain + 12.1-era userland**. Unlike Debian-based distributions, every component is compiled from source code.

| Component | Details |
|-----------|---------|
| Base | Linux From Scratch 12.0 (toolchain) + 12.1-era userland |
| Kernel | Linux 6.18.26 LTS |
| Window Manager | Openbox |
| Panel / Dock | Plank dock + picom + `marux-quicksettings` status bar (2.0.0; 1.x: tint2) |
| Compression | squashfs xz (2.0.0 kernel; 1.x: gzip only) |
| Boot | GRUB |

> **Note**: This guide covers the **x86_64** build. The **ARM64 / Raspberry Pi 4B track** (2.0.0 — separate from-scratch aarch64 rootfs, qemu-chroot builds, Plank dock + picom desktop) is documented in [docs/arm64/](arm64/00-BUILD-REPRODUCIBILITY.md) (reproduction guide, traps catalog, asset reference).

## Build Environment

### Requirements

- **WSL** (Windows Subsystem for Linux) - Ubuntu recommended
- **Packages**: `squashfs-tools`, `grub-pc-bin`, `grub-efi-amd64-bin`, `xorriso`, `mtools`

### Directory Structure

```
/home/administrator/MaruxOS/build/
├── rootfs-lfs/                    # LFS root filesystem
│   ├── bin/
│   ├── boot/
│   ├── etc/
│   │   └── X11/xinit/xinitrc     # X startup script
│   ├── home/
│   ├── lib/
│   ├── root/
│   ├── usr/
│   │   ├── share/
│   │   │   ├── applications/     # .desktop files
│   │   │   └── pixmaps/          # Icons, wallpapers
│   │   └── ...
│   └── ...
│
├── iso-build/                     # ISO staging area
│   ├── boot/
│   │   ├── vmlinuz               # Linux kernel
│   │   ├── initrd.img            # Initial ramdisk
│   │   └── grub/
│   │       └── grub.cfg          # GRUB configuration
│   └── live/
│       └── filesystem.squashfs   # Compressed rootfs
│
└── output/                        # Final ISO files
```

## Build Process

### Step 1: Modify Root Filesystem

Edit files directly in `rootfs-lfs/`:

```bash
# Example: Edit xinitrc
nano rootfs-lfs/etc/X11/xinit/xinitrc

# Example: Add desktop entry
nano rootfs-lfs/usr/share/applications/myapp.desktop
```

### Step 2: Create Squashfs

```bash
cd /home/administrator/MaruxOS/build

# NOTE: 2.0.0 kernels support xz squashfs (cooked-v10 ships xz); 1.x kernels were gzip-only
sudo mksquashfs rootfs-lfs iso-build/live/filesystem.squashfs \
    -comp gzip \
    -e boot \
    -noappend
```

### Step 3: Create ISO

```bash
sudo grub-mkrescue -o MaruxOS-1.0.iso iso-build
```

### Step 4: Copy to Windows (optional)

```bash
cp MaruxOS-1.0.iso /mnt/c/Users/Administrator/Desktop/
```

## Configuration Files

### xinitrc (`/etc/X11/xinit/xinitrc`)

The main X session startup script:

```bash
#!/bin/sh
# Environment setup
export XDG_RUNTIME_DIR=/tmp/runtime-root
mkdir -p $XDG_RUNTIME_DIR

# Network initialization
for iface in /sys/class/net/*; do
    iface_name=$(basename $iface)
    if [ "$iface_name" != "lo" ]; then
        ip link set $iface_name up
        /usr/sbin/dhcpcd $iface_name &
    fi
done

# Set wallpaper
feh --bg-fill /usr/share/pixmaps/maruxos/marux-desktop.png &

# Compositor, dock, status bar, desktop icons (2.0.0)
picom -b --config /etc/xdg/picom.conf
/usr/libexec/bamf/bamfdaemon &
/usr/bin/plank &
/usr/bin/marux-quicksettings &
idesk &

# Window manager = session leader
exec openbox
```

(The 1.x xinitrc started `tint2 &` and kept the session alive with `exec sleep infinity`. The real 2.0.0 xinitrc is generated by `scripts/setup-desktop-config-arm64-v15.sh` / `setup-desktop-config-x86-v1.sh` — read those, not this sketch.)

### Plank dock + `marux-quicksettings` status bar (2.0.0)

| What | Where |
|------|-------|
| Dock launchers | `~/.config/plank/dock1/launchers/*.dockitem` (defaults: `/etc/skel/.config/plank/…`, source: `config/plank/`) |
| Dock settings (theme, icon size, position) | GSettings keyfile backend `~/.config/glib-2.0/settings/keyfile`; defaults in `/usr/share/glib-2.0/schemas/40_maruxos.gschema.override` (`theme='Marux'`) |
| Dock theme | `/usr/share/plank/themes/Marux/dock.theme` |
| Status bar (한/A, WiFi, volume, clock) | `src/marux-quicksettings` (Vala/GTK3), reads `/tmp/marux-ime-mode`, `amixer`, `wpa_cli` |
| Compositor | `/etc/xdg/picom.conf` |

### Desktop Entries

Location: `/usr/share/applications/`

Example `.desktop` file:

```ini
[Desktop Entry]
Name=Terminal
Comment=Terminal Emulator
Exec=qterminal
Icon=utilities-terminal
Type=Application
Categories=System;TerminalEmulator;
```

## Customization

### Adding Applications

1. Compile from source in LFS environment
2. Install to `rootfs-lfs/`
3. Create `.desktop` file in `rootfs-lfs/usr/share/applications/`
4. Rebuild squashfs and ISO

### Changing Wallpaper

Replace: `rootfs-lfs/usr/share/pixmaps/maruxos/marux-desktop.png`

### Modifying the Dock / Status Bar

Dock launchers: edit `config/plank/dock1/launchers/*.dockitem` (and the matching `config/applications/*.desktop`, whose `Icon=` must be an absolute path — icon themes are not shipped), then re-run the config script and rebuild. Dock look: `config/plank/` theme + `40_maruxos.gschema.override`. Status bar: `src/marux-quicksettings` (rebuild with `scripts/install-quicksettings-*.sh`).

Rule (trap #36): any package `make install` may overwrite deployed `.desktop` files — always re-run `setup-desktop-config-*` afterwards; the build gate byte-compares them against `config/`.

## Important Notes

### Compression

Use a compression **the kernel supports**. The 2.0.0 kernel (6.18.26) has xz squashfs built in and `cooked-v10` ships xz (-b 1M) — the main reason the ISO went from 1.24 GB to 238 MB. The 1.x kernel (6.7.4) lacked xz/lzma support, so 1.x images had to be gzip.

```bash
# 2.0.0 (build-2.0.0-cooked-v10.sh)
mksquashfs ... -comp xz -b 1M -Xdict-size 1M

# only if the image must boot on a 1.x kernel
mksquashfs ... -comp gzip
```

### Permissions

Run commands with `sudo` to avoid permission errors during squashfs creation.

### Boot Files

Never overwrite `iso-build/boot/` unless copying from a known working ISO.

## Troubleshooting

### Kernel Panic on Boot

- Check if `vmlinuz` and `initrd.img` exist in `iso-build/boot/`
- Verify the squashfs compression is supported by the kernel (2.0.0: xz OK; 1.x kernels: gzip only)
- Check GRUB configuration

### Black Screen After startx

- Verify xinitrc exists and is executable
- Check for syntax errors in xinitrc
- Ensure `openbox`, `plank`, `marux-quicksettings` are present; check `/tmp/plank.log`, `/tmp/quicksettings.log`, `/tmp/picom.log`

### Network Not Working

Check `/tmp/Network_log.txt` in running system for diagnostics.

## 중요 참고 사항

### 압축

압축은 **커널이 지원하는 것**이어야 합니다. 2.0.0 커널(6.18.26)은 xz squashfs를 내장하며 `cooked-v10`부터 xz(-b 1M)로 출하합니다(1.24 GB → 238 MB의 핵심). 1.x 커널(6.7.4)은 xz/lzma 미지원이라 gzip만 가능했습니다.

```bash
# 2.0.0 (build-2.0.0-cooked-v10.sh)
mksquashfs ... -comp xz -b 1M -Xdict-size 1M

# 1.x 커널로 부팅할 이미지라면 gzip
mksquashfs ... -comp gzip
```

### 권한

squashfs 생성 중 권한 오류를 방지하려면 `sudo`로 명령 실행.

### 부트 파일

작동하는 ISO에서 복사하지 않는 한 `iso-build/boot/`를 덮어쓰지 마세요.

## 문제 해결

### 부팅 시 커널 패닉

- `iso-build/boot/`에 `vmlinuz`와 `initrd.img` 존재 확인
- squashfs 압축이 커널 지원 범위인지 확인 (2.0.0: xz 가능; 1.x 커널: gzip만)
- GRUB 설정 확인

### startx 후 검은 화면

- xinitrc 존재 및 실행 가능 확인
- xinitrc 구문 오류 확인
- `openbox`, `plank`, `marux-quicksettings` 존재 확인; `/tmp/plank.log`, `/tmp/quicksettings.log`, `/tmp/picom.log` 확인

### 네트워크 미작동

실행 중인 시스템에서 `/tmp/Network_log.txt` 확인.
